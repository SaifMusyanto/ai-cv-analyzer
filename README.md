# CV Genius

**CV Genius** is a free AI-powered web app that helps users analyze and build better CVs. Whether you're applying for a job, scholarship, organization, or volunteer role, CV Genius provides detailed feedback and helps you generate an optimized CV instantly using smart templates.

## ✨ Features

- ✅ **CV Analyzer**  
  Upload your CV and get personalized feedback based on relevance, structure, and content.

- 🧠 **AI-Powered CV Builder**  
  Generate a professional CV from scratch using AI and customizable templates.

- 🎯 **Application Type Support**  
  Tailored feedback and generation for jobs, scholarships, organizational roles, and volunteer programs.

- 🖼️ **Template Selection**  
  Choose from modern, minimalist, or classic CV templates.

- ⚡ **Fast and Free**  
  Optimized for speed, usability, and accessibility. No cost to use.

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS, TypeScript  
- **Backend**: Bolt 2, Google Gemini API  
- **Authentication**: Optional (local/session)  
- **Storage**: LocalStorage (for tokens/settings)  
- **Deployment**: Vercel / Netlify
